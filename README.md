## 项目简介

本系统是一个**网络开源威胁情报智能问答系统**，基于多智能体协作架构设计，整合了：

- **向量检索 + 知识图谱**（GraphRAG）实现威胁情报的精准召回
- **多智能体协作**（检索Agent、归因Agent、安全Agent、回答Agent）实现智能问答
- **Streamlit Web界面**提供友好的用户交互体验

用户可以通过自然语言提问，系统自动从威胁情报知识库中检索相关信息，生成带有引用来源和置信度评分的回答。

## 核心特性

| 特性 | 说明 |
|------|------|
| 🔍 **智能问答** | 支持威胁组织、IOC、CVE等威胁情报的自然语言查询 |
| 📚 **引用溯源** | 回答附带原文引用来源，支持追溯验证 |
| 📊 **置信度评分** | 基于检索质量、来源多样性、图谱证据综合评估回答可信度 |
| 🔗 **IOC提取** | 自动从回答中提取IP、域名、文件哈希、CVE编号 |
| 👥 **威胁归因** | 基于多源证据的保守型威胁组织归因分析 |
| 💬 **多轮对话** | 支持上下文连贯的多轮对话 |
| 📄 **文件上传** | 支持上传 txt/docx/pdf 格式威胁报告进行分析 |
| 📤 **对话导出** | 支持导出对话记录为 JSON 格式 |

## 技术栈

### 后端

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 检索服务 | FastAPI + ChromaDB + Sentence-Transformers | 向量检索 + 关键词增强 |
| 知识图谱 | 轻量内存图谱（JSON持久化） | 实体关系存储与扩展 |
| 大模型 | DeepSeek API | 回答生成与推理 |
| 多智能体 | 自研Agent框架 | 检索/归因/安全/回答四Agent协作 |
| 嵌入模型 | all-MiniLM-L6-v2 | 文本向量化 |

### 前端

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| Web框架 | Streamlit | 快速构建交互式UI |
| 文件解析 | PyPDF2 + python-docx | PDF/Word文档解析 |
| HTTP客户端 | requests | 调用后端API |

### 多智能体协作流程

```
用户提问
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. Retrieval Agent（检索Agent）                              │
│    → 调用检索服务，获取相关威胁情报片段 + 图谱路径                  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. Attribution Agent（归因Agent）                             │
│    → 评估证据是否支持威胁组织归因                                 │
│    → 返回 verdict: supported / inconclusive / not_applicable │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. Safety Agent（安全Agent）                                  │
│    → 综合评估：检索分数 + 来源多样性 + 图谱证据 - 归因风险           │
│    → 计算置信度，决定是否拒答                                    │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. Answer Agent（回答Agent）                                 │
│    → 基于证据和归因结果，调用LLM生成回答                          │
│    → 附带引用来源、IOC、置信度                                  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
返回结构化回答给用户
```

## 快速启动

### 环境要求

- Python 3.11
- pip / conda

### 1. 克隆项目

```bash
git clone <repository-url>
cd cyber-threat-intel-qa
```

### 2. 创建虚拟环境

```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
# 或
venv\Scripts\activate         # Windows
```

### 3. 安装依赖

```bash
# 安装所有依赖
pip insatll -r requirements.txt

## 检索服务依赖
cd retrieval_graphrag
pip install fastapi uvicorn chromadb sentence-transformers pydantic pandas numpy

## 问答服务依赖
cd ../lan_shuyang_qa
pip install -r requirements.txt

## Web前端依赖
cd ../web
pip install streamlit PyPDF2 python-docx requests
```

### 4. 配置环境变量

在 `lan_shuyang_qa/` 目录下创建 `.env` 文件：

```env
DEEPSEEK_API_KEY=your_api_key_here
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
RETRIEVAL_URL=http://127.0.0.1:8001
CONFIDENCE_THRESHOLD=0.30
HOST=0.0.0.0
PORT=8000
```

### 5. 一键启动所有服务

```bash
# Windows
./start_all.bat


启动后访问：

| 服务 | 地址 |
|------|------|
| 检索服务 | http://127.0.0.1:8001 |
| 问答服务 | http://127.0.0.1:8000 |
| Web界面 | http://127.0.0.1:8501 |

### 6. 停止所有服务

```bash
# Windows
./stop_all.bat

```

## 评测指标

### 问答评测

| 指标 | 说明 |
|------|------|
| **EM (Exact Match)** | 精确匹配率 |
| **F1 Score** | 问答F1分数 |
| **Recall@K** | 前K个检索结果的召回率 |
| **MRR** | 平均倒数排名 |

### 检索评测

| 指标 | 说明 |
|------|------|
| **Recall@10** | 前10个结果召回率 |
| **MRR** | 平均倒数排名 |

### 归因评测

| 指标 | 说明 |
|------|------|
| **归因准确率** | 威胁组织归因正确率 |

## 已知限制

| 限制 | 说明                  |
|------|---------------------|
| 数据集规模 | 当前仅200条威胁情报记录，覆盖有限  |
| 图谱规模 | 使用轻量内存图谱，非Neo4j生产级  |
| 文件解析 | 复杂PDF（含图片/表格）解析能力有限 |
| 多轮对话 | 会话ID保存在内存中，刷新页面后丢失  |
